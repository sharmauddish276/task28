# React Router Navigation App

## Description

This is a beginner-level React application that demonstrates
navigation between multiple pages using React Router DOM.

## Technologies Used

- React.js
- CSS
- React Router DOM

## Pages

1. Home
2. Dashboard
3. Login
4. Signup

## Features

- Navigation between different pages
- Login form
- Signup form
- Dashboard page
- Home page
- 404 page for invalid routes
- Responsive navigation bar

## Installation

Install the required packages:

npm install
npm install react-router-dom

## How to Run

Start the development server:

npm run dev

Open the local URL shown in the terminal.

## Note

This project demonstrates frontend routing only.
Login and Signup forms do not connect to a backend or database.
